# The Book

nimib book for UniGlyph. `book/index.nim` is compiled and run at docs build
(`nimble docs`), so its code blocks cannot drift from the API. The implemented
surface — load, nominal shaping, retained layout, atlas, and rendering — is
covered in `index.nim`.
